# v0.3.29 – Fix: Lade-/Entlade-Schwingen im günstigen Slot

Behebt [#15](https://github.com/TommiG1/hacs-e3dc-maestro/issues/15).

## Problem
Mit **Aktive Netzladung im low-Slot** lud Maestro den Akku bis zum Ziel (z. B. 90 %)
und hörte dann nur auf zu laden. Das Haus entlud den Akku sofort unter das Ziel, wenige
Minuten später lud Maestro wieder aus dem Netz nach – im Dauertakt.

## Lösung
Ist das Netzlade-Ziel im `low`-Slot erreicht, sperrt Maestro jetzt die **Entladung**
(neue Phase `grid_hold`, „Ziel erreicht (halten)“). Das Haus läuft aus dem günstigen
Netz, der Akku bleibt auf Ziel-SoC. PV-Überschuss darf weiter laden; ein aktiver
Max-SoC-Deckel blockiert die Ladung weiterhin.

## Neue Option
**Entladung im low-Slot nach Ziel sperren** (Einstellungen → Konfigurieren → Tarif &
Kosten). Standard **an**; ausschalten stellt das alte Verhalten wieder her. Bei
prognosebasierter Menge ohne Bedarf (Ziel 0 %) wird nichts gesperrt.

## Parameter zum Variieren
| Parameter | Wirkung |
|---|---|
| Netzlade-Ziel im low-Slot (% SoC) | Bis hierhin wird aus dem Netz geladen, danach gehalten |
| Max. Netzladung/Tag (kWh) | Tagesbudget |
| Entladung im low-Slot nach Ziel sperren | Halten ein/aus |
| SoC-Hysterese | Dämpft Messrauschen am Zielwert |
